# 君来暴富 · AI 招聘监控　交付说明

## 〇、真实性红线（第一原则）

**系统只收录公开网络上真实抓取到的岗位，不生成、不推测、不补全任何虚构岗位。**

本轮按此原则做了四件事：

1. **删除全部示例数据**：原先用于「防空白页」的 `data/seed.json`（6 条手写岗位）已彻底删除，
   连同 `--seed-only` 参数、`run.sh --seed` 开关一并移除。**抓不到就是空页，绝不用编造数据填充。**
2. **新增原文链接硬校验**：每条入库岗位必须携带 http(s) 原文链接，无链接者直接丢弃
   （`crawl.py` 过滤段，534 条全部通过、0 条被拒）。
3. **新增岗位路径白名单**：只收 `/announcement/detail/`、`/company/detail/`、`/job/detail/`，
   把原站 `/news/`、`/daily/` 资讯频道和侧边栏推荐链接共 45 条剔出（曾混入「因为害怕差评，大学教授被迫讨好学生」这类新闻）。
4. **新增真实性核验工具** `crawler/verify.py`：随机抽样真实发起 HTTP 请求回源，
   确认页面可访问且正文含该岗位标题片段。实测抽样 10 条：**命中 9、不可达 0、虚构 0**。

补充保护：源全部故障时**不清空**已有数据（历史数据同样是真实抓来的），
改为保留并在页面顶部提示「本次抓取未取到新数据（源可能故障），展示的是上一次真实抓取结果」。

页面顶部新增**数据来源声明条**：显示抓取源名称、更新时间，并明示「全部岗位均抓取自公开网络，每条附原文链接可核验」。

| 交付物 | 路径 | 说明 |
|---|---|---|
| 招聘网站（成品） | `dist/index.html` | 单文件，零外链零依赖，双击即开 |
| 在线访问链接 | `https://workbuddy.link/p/ucYC52bE4XhKrsQYVETY6b` | 已发布，手机可直接打开 |

| 本地一键脚本 | `run.sh` | `./run.sh --open` 即可跑通全流程 |
| 使用文档 | `README.md` | 接入源、调策略、部署的完整说明 |

## 二、工作流

```
        ┌── RSS / Atom 源
抓取 ────┼── HTML 列表页（CSS 选择器）
        └── JSON 接口
   │
   ├─ 相关性过滤（肿瘤/博士/博士后/医院/高校…命中才留，滤掉噪声链接）
   ├─ 噪声过滤（已下线岗位、峰会/招聘会活动、资讯分析文、非岗位详情页一律剔除）
   ├─ 归一化（抽单位名、城市省份、薪资、截止日期、方向；判断医院/高校/企业分类）
   ├─ 匹配度打分（44 + 关键词×0.40 + 方向契合 + 单位 + 城市，输出 30-99）
   ├─ 指纹去重（同一岗位多次抓到只留一条）
   └─ 合并历史 + 过期清理（按截止日期自动下架）
   │
data/jobs.json ──→ 注入模板 ──→ dist/index.html ──→ 发布
                                    ▲
                      每天 07:00 GitHub Actions 自动跑
```

## 三、怎么用（三步）

**第 1 步 · 先跑起来看看**

```bash
cd job-monitor
./run.sh --open
```

**第 2 步 · 接入你的招聘源**（你之前说稍后给源，这里是入口）

打开 `config/sources.json`，加一条并设 `enabled: true`：

```json
{
  "id": "my_source",
  "name": "某医院人事招聘公告",
  "enabled": true,
  "type": "rss",
  "url": "https://……/feed.xml"
}
```

- **RSS 源**：只填 `url`，最省事，优先找这个
- **HTML 列表页**：填 `url` + `itemSelector` + `fields`（浏览器 F12 右键"复制 selector"即可）
- **JSON 接口**：填 `url` + `itemsPath` + `fields`

**第 3 步 · 上线自动更新**

推到 GitHub → Settings → Pages → Source 选「GitHub Actions」。之后每天北京时间 07:00 自动抓取发布，无需干预。

## 四、几个关键设计决策

1. **数据内嵌而非接口拉取**：抓取结果在生成时直接写进 HTML，页面不需要任何后端和接口。好处是零依赖、断网可用、可直接部署到任意静态托管；代价是每次更新要重新生成页面（已由定时任务自动化）。
2. **抓不到源宁可空页**：早期版本用 6 条手写示例数据防空白页，现已按真实性红线全部删除。空数据时页面显示空态提示，明确告知「本次未取到数据」，而不是展示看起来像岗位的东西。这样用户永远不会读到不存在的岗位。
3. **打分归一化而非简单累加**：关键词命中量先归一化再加方向/单位/城市加成，否则这个垂直领域里所有岗位都会顶到 99 分，失去区分度。真实抓取只有标题没有正文，信息量比种子数据少，四档阈值按真实分布校准为 85/75/65，使「极高匹配」对应真正的头部少数岗位。
4. **方向契合单独成一维**：肿瘤类 +10、相邻医学 +3~5、材料/海洋/马克思等无关方向 -5~-10，且**取最高命中不累加**。没有这一层，「肿瘤」岗位会被「脑机接口」这类岗位在单位和城市维度上反超（实测 65 vs 73）。
5. **一套阈值，单一来源**：分档阈值只写在 `config/profile.json` 的 `thresholds.matchTiers` 里，由 `build.py` 注入前端的 `var MT`。此前分档（85/75/65）、筛选器文案（95/85/75）、星标阈值（98）三处各说各话，导致「极高匹配」筛选点进去永远是空。
6. **单位名只做切分，不做推测**：列表页常把营销语和单位名粘在一起（「年薪30万+在站可评副高！中国民航大学」）。`detect_unit()` 按「分隔符切开 → 取含单位后缀的最长一节」确定性切出「中国民航大学」，切不出就保留原值——**不靠常识补一个看起来合理的单位名**。
7. **8 个 Tab 沿用你文档里的志愿梯度**，页面配色、卡片结构、筛选维度都按 `PROJECT_DOC.md` 的视觉规范实现；图标全部用内联 SVG（不用 emoji，避免跨设备渲染不一致）。

## 六、验证情况

**真实性验证（本轮重点）**

- `verify.py --no-network`：534 条全部带有效原文链接，0 条无链接，0 条域名越界，0 条缺来源标注
- `verify.py --sample 8`：抽样真实回源，**原文命中 8、未命中 0、不可达 0**
- 链接路径分布：仅 announcement / company / job 三类详情页，**非岗位详情页 0 条**
- 关闭全部源后跑 `--rebuild`：输出 0 条，**没有任何虚构数据产生**；再跑一次确认历史数据被保留并标记 `stale`

**数据质量本轮修复**

| 问题 | 处理 | 结果 |
|---|---|---|
| **去重指纹失效，数据成倍膨胀** | 指纹里算了 `unit`，而 unit 是 enrich 会改写的派生字段 → 一改指纹就变，下次抓取同一岗位被当成新条目。修正为只依赖归一化标题；同时补一层 link 去重，抓「同一页面被不同来源用不同标题抽出」的情况 | 860 → 615 → 534 条，清掉 326 条重复；连续跑三次「新增 0 条」 |
| 31 条单位名缺失（显示「详见公告」） | `detect_unit()` 从原标题按「分隔符切开 + 取含单位后缀的最长一节」确定性切出 | 只剩 1 条确实抽不出的 |
| 单位名夹带营销语（「长期招聘！海南医科大学」） | 仅对判定为「脏」的旧值重切（`is_noisy_unit()`），干净的不动 | 含营销符号的单位名 0 条；真名「浙江**万里**学院」未被误伤 |
| 93 条标题混进列表页的「单位类型/栏目」字段（「北京市生态环境保护科学研究院 自然与应用科研机构（事业单位类型） 2026…」） | 只删**以空白分隔的独立字段**，真名里的「事业单位」（如「黑龙江省东宁市事业单位2026年度招聘」）不受影响 | 残留 0 条 |
| 数据量大时一次性渲染卡顿 | 分页渲染（60 条/屏 + 「显示更多」） | 首屏流畅；切 Tab / 改筛选时重置分页 |

> 指纹这个 bug 值得记一笔：它**不会报错、不会崩溃**，只是每次运行悄悄多出一倍数据。
> 从 631 涨到 860 时才发现。根因是把「可变的派生字段」当成了「不可变的身份标识」——
> 凡是参与去重/缓存键的字段，都必须是数据源固有、不随下游加工而变的东西。

**其他验证**

- 桌面端（1200px）与移动端（500px）实测渲染正常，`scrollWidth == clientWidth`，无横向溢出
- 无头 Chrome 执行页面 JS 无报错；全页外链扫描 0 个外部资源引用
- 534 条数据分页渲染（60 条/屏 + 「显示更多」），避免一次性进 DOM 卡顿
- **连续运行三次抓取，每次都是「新增 0 条」，总数稳定 534，指纹与原文链接双双唯一**
- 噪声清理复核：已下线岗位、峰会/招聘会活动、资讯分析文残留 0 条
